
## 📂 File Directory & Descriptions
```text 
To maintain a modular architecture, the system is divided into specific functional scripts. Below is an overview of the core components:

🧠 Logic & Algorithms**
     `A star.py`: The primary engine for informed search.
     `BFS Algorithim.py` & `dfs algorithim.py`: Baseline uninformed search implementations.
     `Heuristics.py`: Mathematical coordinate calculations.
🖥️ Interface & Graphics**
     `GUI.py`: Manages the interactive Pygame window.
     `Visualization.py`: Handles the real-time color-coding of explored nodes.
📊 Experimental Tools**
     `BFS DFS Comparison.py`: Utility script for comparative performance testing.
     `Replanning.py`: Enables the agent to react to dynamic environment changes.

```
